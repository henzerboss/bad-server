## Подготовка к работе
1. Склонировать репозиторий
2. Запустить docker
```bash
docker compose up -d
```
3. Наполнить базу данных
[README.md](.dump%2FREADME.md)
4. Перейти по адресу http://localhost/ и на странице должны быть продукты.
5. На странице http://localhost/login/ можно авторизоваться.
6. Админка находится по адресу http://localhost/admin/
## Исправленные уязвимости
1. XSS: Подключен пакет helmet и используется библиотека sanitize-html внутри валидации Joi (celebrate) для экранирования HTML-инъекций.
2. CSRF: Включена проверка через csurf на все мутирующие запросы, во фронтенд добавлен автоматизированный подхват CSRF-токена.
3. NoSQL-инъекции: Добавлена очистка ключей $ и . через пакет express-mongo-sanitize. Запросы order.ts и customers.ts очищены от прямых связываний с объектами в query.
4. Переполнение буфера: Настроены лимиты в express.json и express.urlencoded (10kb).
5. ReDoS: Изменены опасные регулярные выражения (например, валидация телефона).
6. DDoS: Установлен и настроен express-rate-limit на запросы (200 запросов за 15 минут).
7. Path Traversal: В выдаче статики и перемещении/загрузке файлов настроены проверки путей (path.basename() и path.resolve()).
